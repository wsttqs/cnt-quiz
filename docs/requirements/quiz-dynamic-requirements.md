## 1. 目标

内容系统提供一种**Quiz 文章模板**：根据用户上一层的回答结果，动态决定下一层展示什么题目，最终由各层答案（含分数）组合决定结果页。模板配置通过 **Excel 导入**完成，避免系统侧自建编辑器。

---

## 2. 核心模型

```
Quiz
 ├─ 漏斗层 1（固定入口题组，无父层路由）
 ├─ 漏斗层 2 → 由层 1 的 (胜出标签, 分值区间) 路由进入
 ├─ 漏斗层 3 → 由层 2 的 (胜出标签, 分值区间) 路由进入
 └─ 所有已完成层的 (标签, 分值) → 匹配结果页规则 → 渲染结果页
```

- **Quiz**：一篇文章，由 N 层漏斗 + 1 个默认结果页 + N 条结果页规则组成。
- **漏斗层**：负责确定一个用户维度。
  - 第 1 层：**固定入口题目组**，不存在父层路由。
  - 第 2 层起：通过父层的 (胜出标签, 分值区间) 路由进入对应题目组。
  - 每层可配一个**默认标签**：当本层无标签胜出时，用此标签继续路由下一层。
- **题目组**：一组题目。v1 一道题只能属于一个组，**不允许跨组复用**。
- **标签**：本层产出的维度标识。**命名空间按层隔离**，不同层的同名标签互不相关。
- **分数**：胜出标签的累加分值，带业务语义（典型如严重程度）。仅在本层内分桶使用，**不跨层直接比较**。
- **公共题目**：选项不绑定任何标签（也不带分值），仅用于收集场景信息，**对结果零影响**。
- **结果页**：复用现有结果页模板，本模板只决定匹配哪一页，不重定义页内结构。

---

## 3. 关键流程

```
进入层 1（展示固定入口题组）→ 收集答案
   ↓
按业务配置的规则计算本层标签得分（累加；同分按优先级）
   ↓
本层无任何标签胜出？
   ├─ 是 → 取本层配置的"默认标签"作为本层输出
   └─ 否 → 取最高分胜出标签及其累加分数作为本层输出
   ↓
判断是否触发提前结束条件（业务配置）
   ├─ 是 → 进入结果页匹配
   └─ 否 → 根据 (胜出标签, 分值区间) 按业务配置的匹配顺序路由到下一层题组
   ↓
重复上述过程，直到所有层完成 / 提前结束
   ↓
收集所有已完成层的 (标签, 分值) → 按业务配置的顺序匹配结果页规则
   ├─ 命中某条规则 → 渲染对应结果页
   └─ 全部未命中 → 渲染默认结果页
```

### 3.1 修改答案重算

- 用户在某层内修改任一已选项，点击"下一题"时从**当前层开始向下重算**。
- 上一层已完成的状态**不受影响**（除非业务特别配置允许清空）。

### 3.2 无持久化

- v1 **不做状态持久化**。关页面 / 退出即丢失，下次进入重头开始。
- 不提供"继续上次进度"功能。

## 4. 已确认规则

### 4.1 评分
- 标签分数 = **本层所有被选项对该标签的累加值**。
- **最高分胜出；同分按业务配置的优先级决胜**。
- **评分不跨层累计**。
- **分值取值范围由业务自定义**（每层 / 每标签可不同）。
- 跨层分数**不可直接比较**，只能通过业务定义的分值区间桶间接组合。
- **分值带业务语义**（典型如严重程度），不仅是决胜数字，胜出标签的分数会作为本层输出传递给下游。

### 4.2 选项 ↔ 标签
- 一个选项可同时为多个标签加分，分值由业务配置。
- **公共题目**的选项不绑定任何标签（也不带分值），仅用于分流/兜底，**对结果零影响**。
- 一层所有题 **必答**，无跳过机制。

### 4.3 层间路由
- 路由条件 = **(胜出标签, 胜出标签的分值区间)**。
- 同一 (标签, 区间) 可配置多条候选题目组；按业务配置的**匹配顺序**，**首条命中生效**。
- 第 1 层无路由概念，展示**固定入口题组**。
- 任意一层可配**默认标签**：本层无胜出时使用（默认标签的分数视为 0 / 未定义，不参与分桶）。

### 4.4 提前结束
- 是否提前结束、何时触发、由业务手动配置。
- 触发后跳过剩余层，直接进入结果页匹配。

### 4.5 题目数量
- 每层展示的题目数量（含动态验证题）由业务手动配置。
- v1 一道题只能属于一个题目组，**不允许跨组复用**。

### 4.6 结果页匹配
- 只做一轮组合，**不支持结果页内的二级分流模板**。
- 匹配规则 = **(各层标签组合 + 分值区间组合) → 结果页**，按业务配置的**顺序首条命中**。
- 每篇 Quiz **必须配置默认结果页**，业务未匹配任何规则时走它。
- 结果页内容由现有结果页模板承载，本模板只决定匹配哪一页。

### 4.7 修改答案
- 用户修改当前层的任一选项并提交后，从当前层起向下**重算**（本层分数 + 后续层路由）。
- 已完成的上层不重算。

## 5. 业务可配置项清单

| 类别 | 配置项 | 说明 |
| --- | --- | --- |
| Quiz | 标题 / 描述 / 状态 | 基础信息 |
| Quiz | 默认结果页 | 兜底结果页 |
| 层 | 层顺序 | 漏斗层级与跳转顺序 |
| 层 | 入口题目组（仅第 1 层） | 固定入口 |
| 层 | 默认标签（本层无胜出时用） | 路由兜底 |
| 层 | 提前结束条件 | 可配置多种触发规则 |
| 题目组 | 组名 / 所属层 / 包含题目 | 静态结构 |
| 题目 | 题干 / 顺序 / 所属组 | 静态结构 |
| 选项 | 选项文案 / 顺序 / 绑定标签 / 分值 | 核心评分配置 |
| 标签 | 标签名（按层命名空间隔离） | 维度标识 |
| 标签 | 标签优先级 | 同分决胜依据 |
| 标签 | 分值区间定义 | 业务自定义分桶，供下游路由和结果匹配引用 |
| 路由 | 匹配顺序 | 业务手排，首条命中 |
| 路由 | (层, 标签, 分值区间) → 下一层题组 | 核心路由规则 |
| 结果 | 匹配顺序 | 业务手排，首条命中 |
| 结果 | (各层标签 + 分值区间组合) → 结果页 | 核心结果规则 |

## 6. 配置形态：Excel 导入

业务通过 Excel 维护 Quiz 模板，系统侧**不做前端编辑器**。需要提供：

1. **Excel 模板文件**（.xlsx），含若干 sheet 覆盖 §5 全部配置项。
2. **导入流程**：业务上传 Excel → 系统解析 → 配置校验 → 通过则落库为一条 Quiz 模板。
3. **校验失败的反馈**：明确告诉业务哪一行、哪一列、什么字段有问题。
4. **导入语义**：v1 按"覆盖式"——同 ID 模板重新导入即覆盖，不维护版本。

> Excel 模板的 sheet 结构与字段定义，作为单独的子规格文档输出（v1.3 任务）。

## 7. 数据交付（埋点 / 结果追踪）

业务侧明确需要以下数据：

| 维度 | 内容 |
| --- | --- |
| 用户维度标签 | 每次答题后各层的**胜出标签**（用户画像标签） |
| 结果追踪 | 每次答题最终命中的**结果页 ID** |

系统需在每次 Quiz 答题完成后产出上述数据，用于业务画像与后续优化。详细事件 schema 与落库形式作为开发期任务。

## 8. 案例映射

业务给的 2 个案例只是**多层漏斗 → 结果映射**模型的具体实例，开发可参考但无需为案例定制逻辑。

| 概念 | 案例 1 体现 | 案例 2 体现 |
| --- | --- | --- |
| 多层结构 | 场景 / 摩擦扫描 / 验证 / 承接 共 4 层 | 诊断 / 验证 / 承接 共 2–3 层 |
| 第 1 层固定入口 | 适用场景题 | 居住情况等收集项 |
| 公共题 | 适用场景题（不绑定标签） | 居住情况等收集项 |
| 提前结束 | "无明显方向" → 默认结果页 | 题目组维度确认后即可结束 |
| 标签维度 | 清洁 / 舒适 / 汽车 / 安全 | 问题类型 + 强度 + 偏好 |
| 分数语义 | — | 主维度胜出标签的分数即"严重程度"，用于决定优先级方案与服务承接 |
| 结果映射 | 方向 → 进入对应诊断 / 兜底 | (主维度, 严重度区间) × 偏好 → 优先级方案 |
| 默认结果页 | Routine Is Fairly Well Balanced | （业务按需配） |

## 9. 非目标（v1 明确不做）

- ❌ 跨层标签累计 / 跨层分数直接比较
- ❌ 跨层复合条件判定（统一通过层内辅助标签或分值语义解决）
- ❌ 结果页二级模板 / 嵌套漏斗
- ❌ 动态验证题选项对父层标签的反向打分
- ❌ 题目跨组复用
- ❌ 题目的"跳过"机制（v1 全部必答）
- ❌ 答题状态持久化 / 中途续答
- ❌ 模板多版本并行 / A/B 测试
- ❌ 多语言 / i18n
- ❌ 用户登录态关联
- ❌ 模板编辑器前端（v1 走 Excel 导入）
- ❌ 编辑已发布 Quiz 的版本回滚 / 灰度（v1 走 Excel 重导覆盖）
