Section 3 文件约定 & 校验规则 —— 5 个必配约束
📄文件名约定
  • 文章 ID = 文件名去掉 .xlsx 后缀，全局唯一
  • 文章标题 = 默认与 ID 一致，CMS 后台可改名
  • 状态（draft/published）= 由 CMS 控制，Excel 不维护
🚪入口层
  • 第一个出现的 layer_id = 入口层
  • 入口层必须恰好 1 个 group
  • 入口层不应该有 Routing 规则
🛟兜底规则
  • 每非最后一层配 1 条 (DEFAULT)+(ANY)
  • ResultPages 恰 1 行 is_default=true
  • 每非入口层必须填 layer_default_tag
📑行序约定
  • Structure 行序 = 同层多组的组顺序
  • Questions 行序 = 同组多题的题顺序
  • Routing/ResultPages 行序 = 优先级（首条命中）
🔗跨表 FK 校验
  • Questions.group_id 必须存在于 Structure
  • OptionTags.question_id 必须存在于 Questions
  • OptionTags.layer_id 必须存在于 Structure
  • Routing 两个 FK 必须存在于 Structure
  • ResultPages.condition_expr JSON 内引用必须存在
